## Premium International Corporate Website

---

# 1. PROJECT OVERVIEW

Create a **large, premium, modern, international corporate website** for:

**United Assets Investments SPC**

The website must present the company as a diversified Oman-based business group operating across trading, logistics, industrial supply, commercial services and multiple strategic business sectors.

This must NOT be a simple landing page.

The website should be a complete corporate platform with:

- 20+ pages
- premium visual design
- high-quality photography
- detailed business sector pages
- service pages
- industry pages
- product/category catalogue architecture
- RFQ system
- supplier registration
- partnership forms
- contact forms
- global search
- interactive elements
- animations
- multilingual-ready architecture
- CMS-ready architecture
- SEO
- analytics-ready architecture
- responsive mobile experience

The final website should look like a website of a **large international B2B trading and industrial group**, not a generic small-business template.

# 2. LANGUAGE

The website must be **English ONLY**.

Do not create:

- Arabic version
- Russian version
- language selector
- multilingual navigation

All UI, content, buttons, forms, navigation, metadata and system messages must be in English.

The code architecture can remain localization-ready for future expansion, but the current production website must display English only.
